# Chelamsetty Chaitanya — Portfolio Website

Personal editorial portfolio website for **Chelamsetty Chaitanya** (B.Tech in Artificial Intelligence & Machine Learning, Jain Deemed-to-be University, Bengaluru).

## Features
- Editorial warm-paper & terracotta design with vertical side rails and responsive mobile layout
- Featured project showcase (**AI-Powered Career Platform**) with interactive module tabs and full case-study modal
- Technical skills & personal strengths breakdown
- Academic performance & milestones (**Smart India Hackathon — Qualified Participant**, B.Tech SGPA, 12th/10th Standard)
- Scannable email QR code (`assets/qr-contact.svg`) and one-click email copy

## Structure

.

```bash
python3 -m http.server 8000
```
Open `http://localhost:8000` in your browser.
